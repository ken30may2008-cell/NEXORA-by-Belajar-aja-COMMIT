# Nexora — Live Well. Find Balance.

**Feel good. Spend smart. Find your balance.**

Nexora is a lifestyle optimization and wellness platform designed to help users manage their finances, meals, workouts, and recovery in one integrated space.

Developed by **Team Belajar Aja** as part of the COMMIT project.

## About Nexora

Maintaining a healthy lifestyle involves more than just exercising. It also requires managing daily expenses, maintaining balanced nutrition, planning workouts, and getting enough recovery.

Nexora brings these aspects together into one platform, helping users build healthier and more balanced everyday habits.

## Key Features

### 1. Financial & Meal Tracker
- Track monthly expenses, including gym memberships, supplements, and meal preparation.
- Monitor food-related spending.
- Manage lifestyle expenses within a personal budget.

### 2. Workout Planner
- Organize workout schedules and training routines.
- Use workout templates such as Upper Body, Lower Body, and Pull Day.
- Access an exercise library for workout references.
- Plan and manage training sessions.

### 3. Recovery Room
- Organize sleep schedules and recovery routines.
- Monitor sleep quality.
- Access relaxation features to support recovery.

### 4. Progress Tracking
- Monitor personal fitness progress.
- Review workout and lifestyle records.
- Keep track of personal goals.

### 5. Calendar & Notifications
- Organize daily activities and workout schedules.
- Keep track of upcoming activities.
- Receive reminders and notifications.

### 6. User Profile
- Manage personal account information.
- Access personal preferences and account settings.

## Getting Started

### Prerequisites

Make sure you have installed:
- [Node.js](https://nodejs.org/)
- npm (included with Node.js)
- Git

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/ken30may2008-cell/NEXORA-by-Belajar-aja-COMMIT.git
   ```

2. Navigate to the project directory:

   ```bash
   cd NEXORA-by-Belajar-aja-COMMIT
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL displayed in your terminal.
